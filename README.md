E-Commerce SQL Project

Ever wanted to play around with a realistic e-commerce database without building it from scratch? This project gives you exactly that! I created a full SQL database with users, products, orders, and order items so you can practice queries, analytics, and data modeling on a large dataset.

⸻

What’s Inside
	•	Users: 100+ realistic customers with email, phone, and city.
	•	Products: 1000+ products spanning electronics, fashion, toys, books, and more.
	•	Orders: 200+ orders with multiple items each.
	•	Order Items: Connects products to orders, with quantity and price details.

⸻

Why This Project

This database is perfect if you want to:
	•	Practice SQL joins, grouping, and aggregation.
	•	Run analytics like top customers, most popular products, and monthly revenue.
	•	Showcase a realistic project in your portfolio.

⸻

How to Use
	1.	Open your MySQL client.
	2.	Run the scripts in this order:
	•	01_create_tables.sql → Creates tables.
	•	02_insert_users.sql → Adds users.
	•	03_insert_products.sql → Adds products.
	•	04_insert_orders.sql → Adds orders and items.
	3.	Start querying!

⸻

Example Queries
	•	Top 10 users by order count
	•	Most popular products
	•	Total revenue per month
	•	Users who haven’t placed any orders
	•	Products with low stock
